# aim-frontend-domain

AIM desktop client domain. Use this skill when changing `app/frontend`, Wails bindings, Vue3/Vite/Element Plus UI, or the desktop client's REST/WebSocket protocol bridge.

## Scope

- Wails v2 desktop app under `app/frontend/`.
- Vue3 + Vite + Element Plus frontend under `app/frontend/frontend/`.
- Go bridge packages under `app/frontend/client`, `app/frontend/device`, and `app/frontend/wsclient`.
- Wails generated bindings under `app/frontend/frontend/wailsjs/`.

## Backend Surface Covered

The desktop client talks only to aim-gateway. 完整协议覆盖矩阵见 `references/frontend-coverage-matrix.md`。

### REST 端点（15 个）

| Method | Path | 用途 | App 方法 |
|---|---|---|---|
| POST | `/api/auth/register` | 注册 | `Login()` 内部 |
| POST | `/api/auth/login` | 登录 | `Login()` |
| POST | `/api/auth/refresh` | 刷新 token | `Refresh()` |
| POST | `/api/auth/logout` | 退出 | `Logout()` |
| GET | `/api/users/by-name/{name}` | 搜索用户 | `SearchUsersByName()` |
| GET | `/api/users/by-id/{id}` | 用户详情 | `GetUserById()` |
| POST | `/api/users/friends/{id}` | 添加好友 | Vue 直接调 Wails 绑定 |
| POST | `/api/friends/accept/{id}` | 接受好友 | Vue 直接调 Wails 绑定 |
| POST | `/api/friends/reject/{id}` | 拒绝好友 | Vue 直接调 Wails 绑定 |
| GET | `/api/friends/applications` | 好友申请列表 | `ListFriendApplications()` |
| GET | `/api/friends/me` | 好友列表 | `ListFriends()` |
| POST | `/api/conversations` | 创建会话（直聊/群聊） | `CreateConversation()` / `CreateDirectConversation()` |
| GET | `/api/conversations` | 会话列表 | `ListConversations()` |
| GET | `/api/conversations/history/{id}` | 历史消息（游标分页） | `GetConversationHistory()` |
| GET | `/api/presence/friends` | 好友在线状态快照 | `GetFriendsPresence()` |

### WebSocket

- 升级端点：`GET /ws`（`Authorization: Bearer <access_token>`）
- 帧协议：protobuf 二进制帧（`shared/proto/ws/ws.proto` → `WsFrame`）

Client→Gateway（5 种）：`SEND_MESSAGE`(1)、`HEARTBEAT`(2)、`TYPING`(3)、`READ_RECEIPT`(4)、`ACK`(5)

Gateway→Client（8 种）：`PUSH_MESSAGE`(101)、`PUSH_PRESENCE`(102)、`PUSH_NOTIFICATION`(103)、`PUSH_TYPING`(104)、`RECONNECT`(105)、`SERVER_ACK`(106)、`TOKEN_EXPIRED`(107)、`PUSH_FRIEND_APPLICATION`(108)

## Rules

- Do not import any `app/*/internal` package from `app/frontend`; define client DTOs locally when needed.
- Do not call auth/core/logic gRPC services directly from the desktop client.
- Keep REST and WebSocket I/O in Go Wails bindings; Vue should call generated Wails methods, not implement protocol transport itself.
- For creating conversations, expose `CreateConversation(req CreateConversationRequest)` from Go `App`; for direct-chat backward compatibility keep `CreateDirectConversation(memberID)` as a thin wrapper.
- `CreateConversationRequest` must carry `validate` tags (`required,oneof=direct group` / `required,min=1`); parameter validation errors return `errorx.NewCodeError(errorx.CodeBadInput, ...)`.
- The ordinary-user desktop UI must hide protocol/debug details by default: no REST endpoint labels, protocol catalog, raw frame logs, token dumps, manual heartbeat, read-receipt, or ACK controls in the main client surface.
- Put user-facing auth and chat Vue components under `app/frontend/frontend/src/views` and `app/frontend/frontend/src/components`; keep generated `app/frontend/frontend/wailsjs` files untouched unless regenerated by Wails.
- Do not seed local mock/placeholder conversations or messages in the client. When conversation-list/history APIs are unavailable, render honest empty states instead of fake backend data. After creating a conversation, Vue may add the real backend `conversation_id` to local state for immediate selection.
- Keep `app/frontend` inside the root Go module. Do not create a nested `go.mod`.
- After changing exported Go methods on `App`, run `wails generate module` from `app/frontend`.
- After frontend dependency or UI changes, run `npm install` if dependencies changed and `npm run build` from `app/frontend/frontend`.
- Use Wails v2 imports and generated binding paths:
  - Go runtime: `github.com/wailsapp/wails/v2/pkg/runtime`
  - Frontend bindings: `../wailsjs/go/main/App`
  - Frontend runtime: `../wailsjs/runtime/runtime`
